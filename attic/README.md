# Мансарда — 3D-визуализация

React + three.js (@react-three/fiber, @react-three/drei), сборка — Vite.

    npm install
    npm run dev      # локально
    npm run build    # один файл dist/index.html

- `src/params.js` — размеры, площади, проверки, константы конструктива (`K`)
- `src/Room.jsx` — пол, перекрытия, стены с окном и дверью, свет, размерные линии
- `src/Extension.jsx` — продолжение за стеной с дверью: стеклянная стена-купе, санузел, лестничный проём
- `src/Exterior.jsx` — кровля из металлочерепицы, подсобные пространства за боковыми перекрытиями, фасад с сайдингом и козырёк
- `src/Walker.jsx`, `src/walk.js` — режим прогулки (WASD + мышь) и препятствия на плане
- `src/textures.js` — процедурные текстуры (ламинат, краска, вид за окном, сайдинг, металлочерепица, профлист, OSB)
- `src/App.jsx` — сцена, камеры, режимы, панель управления

Оси: X — поперёк, Y — вверх, Z — от окна (z = 0) через стену с дверью (z = L) до стены-купе (z = L + L2).
Если смотреть от двери на купе (как на фото 2), лестница слева (+X), санузел справа (−X).

Режимы: «Редактор» — орбитальная камера; «Прогулка» — клик по сцене захватывает мышь,
WASD — ходьба, Shift — быстрее, C — пригнуться, Esc — отпустить мышь, M — переключить режим.

Начальное состояние можно задать в адресе: `#view=facade&roof=full&nav=walk`
(view: overview, outside, photo, photo2, window, facade, plan, section; roof: off, half, full).

Мебель: режим «Мебель» (клавиша B) — каталог внизу, предмет ставится кликом, перетаскивается мышью,
R / Q / E — поворот, Del — убрать. Состав: `src/furn.js` (каталог, проверки), `src/Furniture.jsx` (модели),
`src/FurnitureLayer.jsx` (расстановка), `src/BuildUI.jsx` (меню). Расстановка хранится в localStorage.
В прогулке (вид от первого лица) E или щелчок открывает и закрывает ближайшую дверь.

Управление камерой в редакторе: WASD — полёт, Пробел — вверх, Shift — вниз, зажатое колёсико — осмотр вокруг текущего положения.
В режиме «Мебель» выбранный предмет двигается стрелками (шаг 5 см, с Alt — 1 см), стрелки идут относительно взгляда камеры.

Подсобка: дверь 50 × 66 см в левом боковом перекрытии (размеры и положение — в панели «Дверь в подсобку»). В прогулке E открывает её, пролезть можно только пригнувшись (C), внутри потолок скошен и камера опускается.

## Блок «Ремонт» (`src/renovation/`)
Кнопка «Ремонт» в верхней навигации. Настройки хранятся отдельно: `localStorage['attic-renovation-v1']`; кнопка «Сбросить настройки ремонта» не трогает помещение и мебель.

- `data.js` — настройки по умолчанию, каталог материалов и цен, этапы, поверхности.
- `geom.js` — поверхности кабинета в координатах существующей модели, клиппинг по проёмам, построитель призм.
- `calc.js` — чистая логика: подвесы, профили, вата, листы ГКЛ, рейки, доски, смета, потеря площади, проверки.
- `Renovation3D.jsx`, `Section3D.jsx`, `RenovationUI.jsx`, `textures.js` — 3D-слои, разрез с разнесением слоёв, интерфейс, процедурные текстуры.

Начальное состояние через адрес: `#nav=renovation&stage=5`.

Ремонт: потолок. Под натяжным потолком — 5 см пространства и слой фанеры (`ceiling.gap`). После снятия натяжного потолка основание потолка — фанера на 5 см выше. Варианты потолка: «профиль + ГКЛ» или «обрешётка и вагонка прямо на фанеру». Для стен и скатов: вагонка на обрешётку или прямо на ГКЛ по линиям профиля. Батарея в кабинете выносится после ремонта (ниши нет).
